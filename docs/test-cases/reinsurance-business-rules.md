### Rule ID: BR-RNS-001
**Module**: Reinsurance
**Priority**: Critical

#### Rule Description
Treaty numbers must follow the format TRY + 7 zero-padded digits, generated sequentially based on the maximum TreatyID in the table plus one.

#### Source
- **File**: `database/02-stored-procedures/007-reinsurance-sps.sql`
- **SP/Method**: Reinsurance.usp_Treaty_Create
- **Line/Section**: Treaty number generation logic
- **Code Snippet**:
```sql
DECLARE @Sequence INT;
SELECT @Sequence = ISNULL(MAX(TreatyID), 0) + 1 FROM Reinsurance.Treaties;
SET @TreatyNumber = 'TRY' + RIGHT('0000000' + CAST(@Sequence AS VARCHAR(50)), 7);
```

#### Enforcement Mechanism
- Type: SP logic (auto-generated, not user-editable)
- Error Message: N/A (generated internally)
- Behavior: TreatyNumber is always auto-generated by the SP; user cannot specify it directly

#### Linked Test Cases
| Test ID | Description |
|---------|-------------|
| SP-RNS-001 | Verifies TreatyNumber format on creation |
| DV-RNS-001 | Verifies UNIQUE constraint on TreatyNumber column |

#### Edge Cases
| # | Scenario | Expected Behavior |
|---|----------|-------------------|
| 1 | First treaty in empty table | TreatyNumber = 'TRY0000001' (MAX(TreatyID) is NULL, ISNULL returns 0, +1 = 1) |
| 2 | Gaps in TreatyID sequence | Number based on MAX(TreatyID), not count; may skip numbers |
| 3 | TreatyID exceeds 9,999,999 | RIGHT function with 7 digits; number would be truncated to rightmost 7 digits |

### Rule ID: BR-RNS-003
**Module**: Reinsurance
**Priority**: Critical

#### Rule Description
For QUOTA_SHARE treaties, the ceded amount is calculated as GrossPremium multiplied by the treaty's CessionPercent, rounded to 2 decimal places. The retained amount is the remainder.

#### Source
- **File**: `database/02-stored-procedures/007-reinsurance-sps.sql`
- **SP/Method**: Reinsurance.usp_Cession_CalculatePremium
- **Line/Section**: QUOTA_SHARE calculation block

```sql
IF @TreatyType = 'QUOTA_SHARE'
BEGIN
    SET @CededAmount = ROUND(@GrossPremium * @CessionPct, 2);
    SET @RetainedAmount = @GrossPremium - @CededAmount;
END
```

#### Enforcement Mechanism
- Type: SP logic
- Error Message: N/A (calculation, not validation)
- Behavior: Proportional split applied uniformly to all matching policies

### Rule ID: BR-RNS-004
**Module**: Reinsurance
**Priority**: Critical

#### Rule Description
For SURPLUS treaties, premium is ceded proportionally based on the Total Insured Value (TIV) that exceeds the retention amount. If TIV is at or below retention, no premium is ceded. If (TIV - Retention) exceeds the CessionLimit, the proportion is capped.

#### Source
- **File**: `database/02-stored-procedures/007-reinsurance-sps.sql`
- **SP/Method**: Reinsurance.usp_Cession_CalculatePremium
- **Line/Section**: SURPLUS calculation block
- **Code Snippet**:
```sql
ELSE IF @TreatyType = 'SURPLUS'
BEGIN
    IF @TotalInsuredValue > @RetentionAmt
    BEGIN
        DECLARE @SurplusPct DECIMAL(6,4) = 
            CAST((@TotalInsuredValue - @RetentionAmt) AS DECIMAL(18,2)) / @TotalInsuredValue;
        IF @CessionLimit IS NOT NULL AND (@TotalInsuredValue - @RetentionAmt) > @CessionLimit
            SET @SurplusPct = CAST(@CessionLimit AS DECIMAL(18,2)) / @TotalInsuredValue;
        SET @CededAmount = ROUND(@GrossPremium * @SurplusPct, 2);
        SET @RetainedAmount = @GrossPremium - @CededAmount;
    END
    ELSE
    BEGIN
        SET @RetainedAmount = @GrossPremium;
    END
END
```

#### Enforcement Mechanism
- Type: SP logic
- Error Message: N/A
- Behavior: Proportional cession based on TIV exposure above retention

#### Linked Test Cases
| Test ID | Description |
|---------|-------------|
| SP-RNS-002 | Tests surplus calculation with TIV above/below retention |
| FT-RNS-002 | End-to-end premium cession including surplus |

#### Edge Cases
| # | Scenario | Expected Behavior |
|---|----------|-------------------|
| 1 | TIV exactly equals RetentionAmount | No cession (condition is > not >=) |
| 2 | TIV = RetentionAmount + 1 | Very small SurplusPct, near-zero cession |
| 3 | CessionLimit = 0 | SurplusPct = 0 / TIV = 0, no cession |
| 4 | RetentionAmount is NULL | [ASSUMPTION] Comparison with NULL yields FALSE, no cession |

### Rule ID: BR-RNS-006
**Module**: Reinsurance
**Priority**: Critical

#### Rule Description
For EXCESS_OF_LOSS treaties, loss cession only applies when the loss amount exceeds the attachment point. The ceded loss is capped at the treaty layer (ExhaustionPoint - AttachmentPoint). Losses at or below the attachment point are fully retained.

#### Source
- **File**: `database/02-stored-procedures/007-reinsurance-sps.sql`
- **SP/Method**: Reinsurance.usp_Cession_CalculateLoss
- **Line/Section**: EXCESS_OF_LOSS block
- **Code Snippet**:
```sql
ELSE IF @TreatyType = 'EXCESS_OF_LOSS'
BEGIN
    IF @LossAmount > @AttachmentPt
    BEGIN
        SET @CededLoss = LEAST(@LossAmount - @AttachmentPt, @ExhaustionPt - @AttachmentPt);
        SET @RetainedLoss = @LossAmount - @CededLoss;
    END
    ELSE
    BEGIN
        SET @RetainedLoss = @LossAmount;
    END
END
```

#### Enforcement Mechanism
- Type: SP logic
- Error Message: N/A
- Behavior: Layer-based loss allocation; company retains up to attachment, reinsurer covers between attachment and exhaustion

#### Linked Test Cases
| Test ID | Description |
|---------|-------------|
| SP-RNS-003 | Tests XOL loss cession with various loss amounts |
| FT-RNS-003 | End-to-end loss cession calculation |

#### Edge Cases
| # | Scenario | Expected Behavior |
|---|----------|-------------------|
| 1 | LossAmount exactly equals AttachmentPoint | No cession (condition is >, not >=) |
| 2 | LossAmount = AttachmentPoint + 0.01 | CededLoss = 0.01 |
| 3 | LossAmount far exceeds ExhaustionPoint | CededLoss capped at layer size (ExhaustionPt - AttachmentPt) |
| 4 | AttachmentPoint = ExhaustionPoint | Layer size = 0; LEAST returns 0 |

### Rule ID: BR-RNS-007
**Module**: Reinsurance
**Priority**: High

#### Rule Description
For SURPLUS treaties, loss cession uses the same proportional percentage as the most recent premium cession for the same treaty and policy. If no prior premium cession exists, the loss cession percentage defaults to 0 (no loss is ceded).

#### Source
- **File**: `database/02-stored-procedures/007-reinsurance-sps.sql`
- **SP/Method**: Reinsurance.usp_Cession_CalculateLoss
- **Line/Section**: SURPLUS block
- **Code Snippet**:
```sql
ELSE IF @TreatyType = 'SURPLUS'
BEGIN
    DECLARE @ExistingPct DECIMAL(6,4) = 0;
    SELECT TOP 1 @ExistingPct = CessionPercent
    FROM Reinsurance.Cessions
    WHERE TreatyID = @TreatyID AND PolicyID = @PolicyID AND CessionType = 'PREMIUM'
    ORDER BY TransactionDate DESC;

    SET @CededLoss = ROUND(@LossAmount * ISNULL(@ExistingPct, 0), 2);
    SET @RetainedLoss = @LossAmount - @CededLoss;
END
```

#### Enforcement Mechanism
- Type: SP logic (historical lookup)
- Error Message: N/A
- Behavior: Losses follow the same proportional split as the corresponding premium cession

#### Linked Test Cases
| Test ID | Description |
|---------|-------------|
| SP-RNS-003 | Tests surplus loss cession with/without prior premium cession |
| FT-RNS-003 | End-to-end loss cession calculation |

#### Edge Cases
| # | Scenario | Expected Behavior |
|---|----------|-------------------|
| 1 | No prior PREMIUM cession for treaty/policy | @ExistingPct remains 0, CededLoss = 0 |
| 2 | Multiple prior premium cessions | Uses TOP 1 ORDER BY TransactionDate DESC (most recent) |
| 3 | Prior premium cession has CessionPercent = NULL | ISNULL(@ExistingPct, 0) defaults to 0 |

### Rule ID: BR-RNS-008
**Module**: Reinsurance
**Priority**: High

#### Rule Description
Bordereaux reports aggregate cession data by treaty, reporting period (YYYY-MM format), and report type. When generated, all matching PENDING cessions are updated to Status='REPORTED'. The bordereaux is created with Status='DRAFT'.

#### Source
- **File**: `database/02-stored-procedures/007-reinsurance-sps.sql`
- **SP/Method**: Reinsurance.usp_Bordereaux_Generate
- **Line/Section**: Aggregation and status update
- **Code Snippet**:
```sql
SELECT @TotalGross = ISNULL(SUM(GrossAmount), 0),
       @TotalCeded = ISNULL(SUM(CededAmount), 0),
       @TotalRetained = ISNULL(SUM(RetainedAmount), 0),
       @RecordCount = COUNT(*)
FROM Reinsurance.Cessions
WHERE TreatyID = @TreatyID AND AccountingPeriod = @ReportingPeriod
    AND CessionType = CASE @ReportType WHEN 'PREMIUM' THEN 'PREMIUM' WHEN 'LOSS' THEN 'LOSS' ELSE CessionType END;

-- ...

UPDATE Reinsurance.Cessions SET Status = 'REPORTED'
WHERE TreatyID = @TreatyID AND AccountingPeriod = @ReportingPeriod
    AND CessionType = CASE @ReportType WHEN 'PREMIUM' THEN 'PREMIUM' WHEN 'LOSS' THEN 'LOSS' ELSE CessionType END
    AND Status = 'PENDING';
```

### Rule ID: BR-RNS-010
**Module**: Reinsurance
**Priority**: Medium

#### Rule Description
Treaty matching for cession calculations uses policy type, state code, and effective date. A treaty matches a policy when: the treaty Status is ACTIVE, the policy effective date falls between the treaty's effective and expiry dates, and the policy type and state match the treaty's covered filters (or the filters are NULL, meaning all are covered).

#### Source
- **File**: `database/02-stored-procedures/007-reinsurance-sps.sql`
- **SP/Method**: Reinsurance.usp_Cession_CalculatePremium
- **Line/Section**: Treaty cursor query
- **Code Snippet**:
```sql
SELECT TreatyID, TreatyType, CessionPercent, RetentionAmount, CessionLimit, AttachmentPoint, ExhaustionPoint
FROM Reinsurance.Treaties
WHERE Status = 'ACTIVE'
    AND @EffectiveDate BETWEEN EffectiveDate AND ExpiryDate
    AND (CoveredPolicyTypes LIKE '%' + @PolicyType + '%' OR CoveredPolicyTypes IS NULL)
    AND (CoveredStates LIKE '%' + @StateCode + '%' OR CoveredStates IS NULL);
```

#### Enforcement Mechanism
- Type: SP query logic (WHERE clause filtering)
- Error Message: N/A
- Behavior: Only matching treaties are iterated for cession calculation

#### Linked Test Cases
| Test ID | Description |
|---------|-------------|
| SP-RNS-002 | Tests treaty matching with various policy types and states |
| SP-RNS-003 | Tests treaty matching for loss cessions |

#### Edge Cases
| # | Scenario | Expected Behavior |
|---|----------|-------------------|
| 1 | CoveredPolicyTypes is NULL | Treaty matches ALL policy types (OR condition) |
| 2 | CoveredStates is NULL | Treaty matches ALL states (OR condition) |
| 3 | LIKE pattern partial match | 'HO3' in CoveredPolicyTypes='HO3,HO5' matches via '%HO3%' |
| 4 | [ASSUMPTION] Partial match risk | 'HO3' LIKE could match 'WHO3' in theory if present in list |
| 5 | Policy EffectiveDate on treaty boundary | BETWEEN is inclusive, treaty matches |
